# 《谁会爆炸》联机测试说明

## 局域网

1. 房主选择“开房”。
2. 其他玩家选择“加入”，点击“扫描局域网房间”，再点击发现的房间即可自动填写地址和端口。
3. 房主也可以在大厅点击“复制房主地址”发给其他人。

## Radmin VPN

1. 所有人先加入同一个 Radmin VPN 网络，并确认彼此在线。
2. 房主开房。大厅会显示并优先复制 `26.x.x.x` 地址。
3. 客户端可尝试扫描；若虚拟网卡不转发广播，则手动填写房主的 `26.x.x.x` 地址和游戏端口。
4. Windows 防火墙首次询问时需要允许专用网络访问。

## 樱花内网穿透 / Sakura FRP

1. 房主在樱花面板创建 TCP 隧道，本地地址填 `127.0.0.1`，本地端口填游戏大厅显示的端口（默认 `7788`）。
2. 启动隧道后，把面板提供的服务器域名和远程端口发给客户端。
3. 客户端可以直接在地址栏粘贴 `域名:远程端口`，也可以分别填写地址和端口。
4. 游戏状态与语音都经同一条 TCP 连接中继，不需要另外映射语音 UDP 端口。

## 语音

- 默认按住 `V` 键发言。
- 在开始界面设置或游戏内 `Esc` 设置里，可以切换为“自动检测说话并传输”。
- 设置内可录制 3 秒并本地回放，测试内容不会发送到房间。
- 建议使用耳机，避免扬声器回声再次进入麦克风。

## 自定义规则

房主可在开始界面的设置中选择地图尺寸、等效炸弹数量、初始概率偏移、每轮偏移增长以及回合限时。开局后由房主把这些参数同步给所有客户端。

限时结束仍未操作时，由房主权威端自动翻开一格，避免玩家离开后整局卡住。
