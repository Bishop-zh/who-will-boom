# 战绩统计与 UGUI 预制体验收

本轮使用用户提供的新战绩图集，标题为“战绩统计”。弹窗包含总对局、胜场、胜率、最高连胜、近期十局、单局详情、胜率环图、单人/多人模式分布及刷新、关闭功能。数据来自本机完成的实际对局，新版开始积累记录，不会生成虚假的旧历史。

## 可编辑预制体

主项目 `Assets/Resources/BombTavern/Prefabs/UI` 已有八个 UGUI 预制体：HomeMenu、RulesTutorial、SettingsPopup、StartGameSetup、StatisticsPopup、GameSetupRules、GameOver、LobbyPanel。运行时加载这些资源；在 Unity Prefab Mode 调整后保存即可。功能节点和绑定注意事项见 `Docs/UI预制体调整说明.md`。

本轮补齐对局规则、结算、等待连接页，并修正规则遮罩根节点和显示顺序，防止打开规则时误点底层返回按钮。四个新增预制体无缺失脚本；按钮动效脚本使用独立同名文件保存。

## 统计实现

- `MatchStatisticsTracker` 观察真实会话完成状态；同一局只保存一次，排除菜单演示局、晚到的已结束快照与 AI 座位。
- 记录模式、胜负、时间、回合数、翻格、命中和道具使用次数；累计总数和连胜不受详情上限影响。详情保留最近 1000 局，页面展示最近 10 局。
- JSON 位于 `Application.persistentDataPath/match-statistics-v1.json`，使用临时文件、原子替换及备份。主文件损坏可读取有效备份；主备份均损坏时保留文件并提示，避免覆盖原记录。
- 环形图继承 `MaskableGraphic`，在 `OnPopulateMesh` 中按胜率生成金色/灰色环段；模式条采用 `Image.Type.Filled` 和 `fillAmount`。昵称按纯文本显示，避免富文本标签影响详情排版。

技术依据：[Unity Graphic.OnPopulateMesh](https://docs.unity3d.com/cn/2019.2/ScriptReference/UI.Graphic.OnPopulateMesh.html)、[Unity Image.Type.Filled](https://docs.unity3d.com/cn/2019.2/ScriptReference/UI.Image.Type.Filled.html)。

另有 29 项核心检查通过，包含持久化、去重、模式和连胜、损坏恢复、非法历史拒绝、详情上限、客户端重复结束快照、八个预制体组件完整性及规则根节点铺满父画布。

统计弹窗节点在四种尺寸均未检测到文字溢出或越界。全画布记录包含旧主页箭头“›”的 TMP 溢出标记；这些来自背景主页，并非统计弹窗节点，不据此宣称全项目所有文本标记为零。

有耗时的点击回调平均约 3.2–3.4 毫秒；最慢约 108–115 毫秒，发生在结算返回主页的场景重载。此数据是回调执行时间，不等于真实鼠标到屏幕显示的延迟。

覆盖首次教程关闭、设置三页及下拉框、四角色切换、单人/开房/加入界面、规则遮罩、结算按钮、等待连接昵称回调、战绩空态/记录/详情/刷新/内外关闭、0%/100% 环图，以及两局会话结算后的真实统计更新。

最终证据为 `Build/StatisticsUI/Verified_<尺寸>/ui-tests.json` 与 PNG，核心报告为 `Build/statistics-core-tests.json`，构建日志为 `Build/statistics-verified-build.log`。此前 Candidate、Final、Release 目录是中间版本，不能替代最终 Verified 证据。185 个相关源码、素材和预制体与后台构建副本 SHA256 一致，记录在 `Build/statistics-delivery-hashes.json`；交付播放器 137 个原始构建文件也逐一核对一致。

## 验证边界

没有操作前台。真实物理输入、系统全屏切换、恢复默认中的系统窗口切换、真实麦克风、公网/跨机联机均未执行。等待连接页只验证预制体和本机回调；不代表跨机连接已通过。测试夹具中的 128 局等数字仅用于验证图表，未放入正式玩家存档。

独立陪审沿用用户指定的 GPT-6 Sol、中度思考，复验对象为最终同步版战绩页、八个预制体及相关回归。陪审独立重算185个文件哈希、核对29项核心报告和四份131项后台报告，并亲看最终统计、详情、规则遮罩、结算、大厅及四尺寸统计截图。实际裁定为本轮验证范围内“通过”，此前必修项闭合；未见明显新增损失。裁定不覆盖前述真实设备和网络路径，也不保证未知分辨率。写入范围仅本项目源码、资源、说明与构建产物，未修改陪审技能规则。
