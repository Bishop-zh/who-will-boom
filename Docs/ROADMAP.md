## 二、做对了什么（不要动）

1. `TrueRisk`/`DisplayedRisk` 分离 + 回合漂移 =「颜色会撒谎」，核心机制原创且完整，不是扫雷换皮。
2. 确定性模拟 + 状态同步，网络架构选对，省掉后续对账麻烦。
3. 数据驱动彻底，改数值不碰代码。
4. 道具效果注册表是正确的扩展点。
5. 无头自检探针是团队级资产，可进 CI。
6. 保密设计三层自洽：私人读数 + `secret` 标志 + 按座位过滤快照。

## 三、三个结论性判断（决定优先级）

### 判断 1：UI 的问题不是「太简洁」，是「没有视觉语言」

IMGUI 默认皮肤决定了它只能长这样，再加控件也不会精致。
缺的不是功能，是设计语言（色板 / 字阶 / 间距 / 圆角阴影 / 组件规范）。
**先定规范再迁移**，否则只是把难看的控件搬进 UGUI。

### 判断 2：最大的感知提升不是 UI，是音频

当前 0 个音频文件。完全没声音的游戏，UI 再精致也会被评为「像个原型」。

### 判断 3：节奏的真问题是「75% 的时间你在看别人玩」

四人局只有 1/4 时间拥有决策权。这是玩法层面最被低估的缺陷 ——
不会让游戏崩，但会让玩家第 3 回合开始看手机。

## 四、UI 专项

### 4.1 IMGUI 为什么带不出去

手算像素矩形 → 换分辨率错位；无 Canvas Scaler → 做不到分辨率无关；
无动画体系 → 面板「啪」地出现；默认皮肤 → 一眼调试工具；
中文排版差（中文游戏的门面）；`OnGUI` 每帧重建布局是性能热点；手柄与改键基本无解。

### 4.2 迁移路径（不要一次性重写）

1. 抽数据层（1~2 天）：HUD 改读 `HudViewModel` 纯数据，后续迁移变机械替换。
2. 定设计语言（1 天，收益最大）：色板 / 4 级字阶 / 8px 栅格 / 组件集。
3. 迁移 HUD（3~5 天）：UGUI + TMP，Scaler 用 Scale With Screen Size。
4. 迁移菜单与大厅（3~5 天）。
5. 删除 IMGUI，只留调试浮层。

### 4.3 正式版必须补的界面

| 界面 | 现状 | 要点 |
|---|---|---|
| 设置 | 无 | 音量四路（主/音乐/音效/语音）、画质、分辨率、按键、语言 |
| 暂停 | 无 | 单机必须；联机显示连接状态 |
| 新手引导 | 无 | 见 5.1，是玩法门槛问题 |
| 道具图鉴 | 无 | 10 件数据已齐，只差展示 |
| 结算页 | 极简 | 胜者、各人数据、回合曲线、再来一局 |
| 掉线提示 | 有逻辑无界面 | `TakeBackSeatFromBot` 已实现，缺可见提示 |

## 五、玩法缺口

### 5.1 新手引导（最高优先级）

「颜色会过期」是全部乐趣，也是最大理解门槛。不解释的话玩家会理解为
「这游戏在骗我」而不是「在考验我」。做成一局脚本化教学：

```
第 1 回合：只让翻 3 格，颜色全对          → 建立「颜色可信」
第 2 回合：明示漂移，颜色没变但真相变了    → 制造认知冲突
第 3 回合：送探查器，亲手戳破一次谎        → 完成认知闭环
```

### 5.2 再来一局闭环（留存核心）

`结算 → 复盘 → 再来一局（同批人换种子）→ 返回大厅`。比任何 UI 美化都重要。

### 5.3 幽灵模式（淘汰后有事做）

死后能看到全部盘面真相当解说。实现成本最低（私有读数换全局真相），留存收益明显。

### 5.4 AI 性格分化

现在每个 AI 行为一样，玩两局就觉得「就这」。需要三档难度 + 性格（激进/保守/阴险）。

## 六、节奏专项

```
单回合：真人思考 3~8s / AI 延迟 1.2~2.2s
四人一轮：8~15s   一整局：2~4min（全 AI）/ 6~12min（含真人）
```

问题不在总时长，在于形状是平的。

- **等待期空转** → 微决策：下一手预选、随时插旗、道具预选。把等待变成准备。
- **无节奏起伏** → 危险预警（盘面风险 >50% 转紧张音乐）、连续安全连锁、剩 1 命角色紧张待机。
- **回合推进无感** → 回合开始给一次视角拉远 + 音效 + 横幅。
- **真人无限思考** → 软性倒计时 45s，超时自动托管一回合（复用 `H` 键开关）。

## 七、上线就绪度

设置持久化、本地化（i18n 表）、画质与分辨率、手柄改键、性能剖析
（`GameHud` 每帧重建布局是热点）、单元测试（覆盖 `RiskBoard` / `GameSession`）。

## 八、已知技术债

FBX 无 Avatar（骨骼剪辑未真正播，现在靠程序化层撑）；语音只有能量门限
（无 VAD / 抖动缓冲 / 回声消除）；无单元测试。

## 九、执行顺序

**第一轮｜去掉「原型感」**（收益/成本比最高，不涉及 UI 重写）

- [x] **1. 音效系统** —— `SfxLibrary`（运行时程序化合成 15 个音效，零二进制资源）
      + `AudioDirector`（事件驱动播放、四路音量、音源池、保密事件静音）
- [x] **2. 结算 + 再来一局闭环** —— 结算面板给出四人战绩（机会/翻开/踩雷/道具）
      + 「再来一局」「返回大厅」两个出口；联机由 `LanNetworkManager.RestartGame()` 处理房主重开
- [x] **3. 幽灵模式** —— 本地玩家出局后，面板切到真实概率视角（压暗偏冷色以区分），
      HUD 显示「幽灵视角 · 颜色即真实概率」，淘汰者从流失点变成观战者

> 附带发现：`StateSnapshot` 发送 `displayedRisk` + `Staleness`，而客户端还原
> `trueRisk = displayed - staleness` —— **数学上等价于直接发真实值**。
> 注释声称「不发真实值本身」不成立。既然幽灵模式需要它，暂时保留；
> 若要真正防作弊，应改为发送**分档的**偏差提示（如 ±10% 一档），而不是精确浮点。

**第二轮｜UI 正式化**

- [x] **定设计语言** —— `UiTheme.cs`：色板（表面 4 级 / 文本 4 级 / 语义 6 色）、
      4 级字阶、8px 间距栅格、**程序化圆角面板**（9 宫格，圆角不会被拉伸）、
      按钮三态底图。已应用到 HUD 与主菜单。
      配套修正：轮次条高度、玩家卡高度抽成 `UiTheme.RoundBarHeight` /
      `PlayerCardHeight` —— 原来各处写死偏移，换内边距立刻互相重叠。
- [x] **迁 HUD 到 UGUI** —— `UiKit`（画布 / CanvasScaler 分辨率自适应 / 主题化控件）
      + `GameHudUgui`（轮次条 / 操作权 / 玩家卡 / 事件流 / 道具栏 / 准星卡 / 横幅 / 呼吸框 / 结算）。
      旧 IMGUI `GameHud` 已删除。
      - 字体决策：用 **UGUI 传统 Text + 系统动态字体**，不用 TMP。
        因为 TMP 依赖 `TMP Settings.asset`，缺失时 `Awake()` 直接抛空引用、
        一个字都不显示；而该资产只能靠导入 TMP Essentials 得到，导入是**异步**的，
        `-batchmode -quit` 跑不完。传统 Text 与现有 IMGUI 的中文方案一致，零资产依赖。
        TMP 留作后续可选升级（导入好后只需替换 `UiKit.Label` 的实现）。
- [ ] 迁菜单与大厅（`PreGameMenu` / `LobbyUI` / `MainMenuUI` 仍是 IMGUI）
- [ ] 设置 / 暂停 / 道具图鉴

### 本轮同步修掉的体验问题

- [x] **血量灯泡外凸** —— 原来用平贴的碟片，几乎完全顺着屏面法线，
      从桌子对面看只剩一条边，读不出亮了几盏。改成**球形灯罩**（各向同性），
      并按 `bulbProtrusion` 精确控制露出比例（球心放在 (2p-1) 倍半高处）。
- [x] **护盾视觉** —— `ShieldVisual`：一圈自发光小球绕角色旋转，
      数量随剩余层数变化，被挡下时整圈闪一下。
      护盾原本只是玩家卡上的数字，对手完全看不见 —— 这在博弈上是缺失的信息。
      用不透明小球而不是半透明球罩：不需要引入透明着色器与渲染队列假设。
- [x] **道具效果加强** —— `BoardVfx`：把道具效果**精确落到被作用的格子上**，
      而不是笼统地在角色/平板附近闪一下。问题的本质不是强度不够，是**没有指向性**。
      整行/区域扫描按环由内向外扩散，做出「扫描」的过程感。
- [x] **角色腿部被身体吃掉（建模疏漏，非设计）** —— 以球形炸弹为例：
      `hip_x = r*0.46`、髋高 `h*0.22`，而身体球在 z=0.202 处横截面半径 0.381，
      髋关节离轴仅 0.212 → 整条腿段都在肚子里，只有靴子尖露出。
      已把 `Tools/Blender/build_bomb_characters.py` 改为 `hip_x = r*1.02`、
      髋高 `h*0.30`，腿会贴着轮廓外侧垂下。
      **⚠ 需重新导出 FBX 才生效，而本机未安装 Blender** —— 参数已修好，待有 Blender 时重跑。
